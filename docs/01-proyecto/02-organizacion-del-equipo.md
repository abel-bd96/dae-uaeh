## 2. Responsabilidades propuestas

### Desarrolladores

Responsables principales de:

- Arquitectura MVC.
- Backend en PHP.
- Integración con SQL Server.
- Integración con sistemas externos.
- Revisiones de código backend y frontend.
- Desarrollo frontend.
- Bootstrap.
- JavaScript.
- Integración de vistas.
- Consumo de servicios internos.

### Diseñador UX/UI

Responsable de:

- Wireframes.
- Prototipos.
- Diseño visual.
- Experiencia de usuario.
- Sistema de componentes.
- Definición de flujos, navegación y jerarquía visual.
- Diseño de la experiencia del usuario.

### Responsable de Base de Datos

Responsable de:

- Modelo conceptual.
- Modelo estructural.
- Modelo entidad-relación.
- SQL Server.
- Índices.
- Optimización.
- Integridad de datos.
- Procedimientos almacenados.
- Respaldos.
- Migración de datos.
- Diseño de vistas.
- Administración de usuarios y roles.

### Responsable de Infraestructura / Servidores

Responsable de:

- Configuración de servidores locales de prueba (web y de datos).
- Configuración de DNS.
- Configuración de PHP.
- Configuración de SQL Server.
- Seguridad.
- Respaldos.
- Monitoreo.
- Despliegues.
- Recuperación ante fallos.

### Responsable Técnico

Responsable de:

- Arquitectura.
- MVC.
- Patrones.
- Seguridad.
- Estructura del proyecto.

## 3. Responsabilidad compartida

### Análisis

Todos participan en el análisis.

No se busca que únicamente una persona conozca el negocio, sino que el conocimiento de los procesos y requerimientos se comparta entre los integrantes del equipo.
